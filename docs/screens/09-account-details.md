# User Guide: Account Ledger & Transaction History

[← Back to Edit Account](08-edit-account.md) | [Next: 10 - Custom Account Types →](10-account-types.md)

---

The **Account Ledger** screen presents the full transaction history for a specific bank account. From here, you can search, filter by period, review category assignments, import statement files, and apply automated categorization rules.

---

## 1. Visual Overview & Action Callouts

![Account Details & Transaction Ledger](../images/screens/09-account-details-screen-annotated.png)

---

## 2. Action Reference Table

| Marker | UI Element | Action Type | What to do |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Text Search** | **FILL IN** | Enter a keyword (payee name, reference, or note) to find specific transactions. |
| <kbd>2</kbd> | **Period Selector** | **SELECT** | Choose a time frame (e.g., Current Month, Previous Month, Year to Date, or All Time). |
| <kbd>3</kbd> | **"Filter" Button** | **CLICK HERE** | Click to apply your search keyword and time frame filters to the transaction ledger. |
| <kbd>4</kbd> | **"Import Transactions"** | **CLICK HERE** | Click to open the statement import wizard pre-configured for this specific account. |
| <kbd>5</kbd> | **"Apply Rules" Button** | **CLICK HERE** | Click to run your automated categorization rules on all unassigned transactions in this account. |

---

## 3. Account Insights & Ledger Controls

- **Account Balance Card**: Displays current account balance, IBAN, and OFX identifier in the top header.
- **Category Breakdown Chart**: Visualizes expense and income distribution for the selected period directly above the ledger.
- **Transaction Table**: Shows operation date, payee/label, category badge, tracking status tag, and debit/credit amounts.

---

## 4. Step-by-Step Procedure

1. **Find past operations**:
   - Type a merchant name or keyword in the **Search** box (<kbd>1</kbd>).
   - Select the desired time range from the **Period** dropdown (<kbd>2</kbd>).
   - Click **Filter** (<kbd>3</kbd>) to refresh the ledger.
2. **Import statements**:
   - Click **Import Transactions** (<kbd>4</kbd>) to load a CSV or OFX file downloaded from your bank.
3. **Automate classification**:
   - Click **Apply Rules** (<kbd>5</kbd>) to automatically match keywords to categories and tags.
