The **Category Form** lets you define new spending classifications or modify existing ones, customize icons and color codes, configure multi-language translations, and designate salary income categories.

## 2. Action Reference Table

| Marker | UI Element | Action Type | What to do |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Category Name Input** | **TYPE HERE** | Enter the primary display name for this category (e.g., *Groceries*, *Vehicle Maintenance*). |
| <kbd>2</kbd> | **Multi-Language Translations** | **SELECT / TYPE** | Provide localized translations for different languages (English, French, Spanish, German). |
| <kbd>3</kbd> | **Color Picker & Hex Code** | **PICK COLOR** | Choose a distinctive color for charts, graphs, and transaction badges. |
| <kbd>4</kbd> | **Parent Category Dropdown** | **SELECT OPTION** | Select a parent group to make this a subcategory, or leave empty to create a top-level parent group. |
| <kbd>5</kbd> | **Icon Selector & Preview** | **CLICK HERE** | Open the icon picker to select a representative icon from the built-in library. |
| <kbd>6</kbd> | **"Save Category" Button** | **CLICK HERE** | Save the category and return to the category explorer. |

---

## 3. Top-Level vs Subcategory Classification

- To create a **Top-Level Parent Category**: Leave the **Parent Category** field (<kbd>4</kbd>) empty.
- To create a **Subcategory**: Select an existing parent category in dropdown (<kbd>4</kbd>). The subcategory will automatically inherit the income or expense classification of its parent.

---

## 4. Step-by-Step Instructions

1. **Enter the category name**: Type the title in field (<kbd>1</kbd>).
2. **Assign parent group**: Select a parent in dropdown (<kbd>4</kbd>) or leave blank for a new group.
3. **Pick an icon & color**: Click **Choose Icon** (<kbd>5</kbd>) and select a badge color (<kbd>3</kbd>).
4. **Configure translations**: Select alternate languages (<kbd>2</kbd>) if you use multilingual reporting.
5. **Save**: Click **Save Category** (<kbd>6</kbd>).
