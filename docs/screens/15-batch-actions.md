## 2. Action Reference Table

| Marker | UI Element | Action Type | What to do |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Master "Select All" Checkbox** | **CLICK / TOGGLE** | Select or deselect all visible transactions in the current table page with one click. |
| <kbd>2</kbd> | **Row Selection Checkbox** | **CLICK / TOGGLE** | Select individual operations to include in the batch operation. |
| <kbd>3</kbd> | **Selected Items Counter** | **STATUS BADGE** | Displays the real-time count of currently selected operations awaiting action. |
| <kbd>4</kbd> | **Batch Reconciliation Action** | **CLICK HERE** | Apply reconciliation status (e.g., mark as *Reconciled* or *Cleared*) across all selected transactions. |
| <kbd>5</kbd> | **Clear Selection Button** | **CLICK HERE** | Deselect all rows and dismiss the bulk action floating toolbar. |

---

## 3. Best Practices for Monthly Statement Reconciliation

1. **Filter by statement period**: Select the previous month using the period selector in the ledger header.
2. **Match with bank statement**: Tick off the checkboxes (<kbd>2</kbd>) for operations confirmed on your bank statement.
3. **Bulk reconcile**: Click the **Reconcile** action button (<kbd>4</kbd>) to lock all verified operations.
4. **Clear selection**: Dismiss the toolbar (<kbd>5</kbd>) to return to the normal ledger view.
