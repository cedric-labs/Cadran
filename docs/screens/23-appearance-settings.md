The **Appearance Settings** page allows you to tailor Cadran's typography, text scale, table density, and ledger layout modes to fit your preferred desktop environment and screen resolution.

## 2. Action Reference Table

| Marker | UI Element | Action Type | What to do |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **"Add Font" Button** | **CLICK HERE** | Open the dialog to add custom Google Fonts or system fonts to your typography catalog. |
| <kbd>2</kbd> | **Typography Font Selection** | **SELECT OPTION** | Choose your active typeface (Inter, Roboto, Segoe UI, Fira Code, Outfit...). |
| <kbd>3</kbd> | **Text Size Scale** | **SELECT SIZE** | Adjust font sizing from Compact (13px) to Large (16px) for maximum readability. |
| <kbd>4</kbd> | **Ledger Display Mode** | **TOGGLE MODE** | Choose between *Compact* (streamlined, expandable) and *Comfort* (all raw details visible). |
| <kbd>5</kbd> | **"Save Preferences" Button** | **CLICK HERE** | Apply your chosen visual preferences across the entire application immediately. |

---

## 3. Compact vs Comfort Display Modes

- **Compact Mode**: Designed for power users reviewing extensive transaction histories. It displays cleaned labels and keeps table row height minimal. Clicking on any row reveals raw statement memos and technical details.
- **Comfort Mode**: Displays complete raw bank descriptions, account notes, and check references directly on each row without requiring extra clicks.

---

## 4. Step-by-Step Instructions

1. **Pick your typeface**: Browse the font catalog and select your favorite typography (<kbd>2</kbd>).
2. **Set text scale**: Choose a font size (<kbd>3</kbd>) that matches your monitor's DPI and scaling.
3. **Choose table density**: Select Compact or Comfort mode (<kbd>4</kbd>) depending on your workflow.
4. **Save and apply**: Click **Save Preferences** (<kbd>5</kbd>).
