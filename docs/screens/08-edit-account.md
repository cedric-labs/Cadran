# User Guide: Edit & Configure Bank Account

[← Back to Create Account](07-create-account.md) | [Next: 09 - Account Ledger & History →](09-account-details.md)

---

The **Edit Account** screen allows you to modify the parameters of an existing account, adjust its opening balance baseline, or archive it when an account is closed.

---

## 1. Visual Overview & Action Callouts

![Edit Account Screen](../images/screens/08-edit-account-screen-annotated.png)

---

## 2. Action Reference Table

| Marker | UI Element | Action Type | What to do |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Account Name** | **FILL IN** | Update the label of your account if you wish to rename it. |
| <kbd>2</kbd> | **Account Type** | **SELECT** | Change the classification group (Checking, Savings, Investment, or Credit Card). |
| <kbd>3</kbd> | **Initial Balance** | **FILL IN** | Adjust the starting balance if you need to correct past reconciliation discrepancies. |
| <kbd>4</kbd> | **Archive Switch** | **OPTIONAL** | Toggle this switch on if the bank account is closed. The account will be hidden from the dashboard while preserving all historical records. |
| <kbd>5</kbd> | **"Save changes"** | **CLICK HERE** | Click to apply and save your updates. |

---

## 3. Step-by-Step Procedure

1. **Rename the account (optional)**:
   - Edit the text in the **Account name** field (<kbd>1</kbd>).
2. **Reclassify the account (optional)**:
   - In the **Account type** dropdown (<kbd>2</kbd>), switch to another asset type if needed.
3. **Correct opening balance (optional)**:
   - In the **Initial balance** field (<kbd>3</kbd>), enter the revised opening balance.
4. **Archiving a closed account**:
   - Flip the **Archive this account** toggle (<kbd>4</kbd>) to safely remove it from active views without deleting past transactions.
5. **Apply modifications**:
   - Click the green **Save changes** button (<kbd>5</kbd>).
