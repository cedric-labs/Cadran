## 2. Tableau de Référence des Actions

| Repère | Élément d'Interface | Type d'Action | Consigne |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Adresse E-mail** | **RENSEIGNER** | Saisissez votre adresse électronique enregistrée. |
| <kbd>2</kbd> | **Mot de Passe** | **RENSEIGNER** | Saisissez votre mot de passe secret. Les caractères sont masqués par confidentialité. |
| <kbd>3</kbd> | **Se souvenir de moi** | **OPTIONNEL** | Cochez cette case si vous utilisez un appareil personnel afin d'éviter d'avoir à vous reconnecter à chaque fois. |
| <kbd>4</kbd> | **Bouton "Se connecter"** | **CLIQUER ICI** | Cliquez sur ce bouton pour valider vos identifiants et accéder au tableau de bord. |
| <kbd>5</kbd> | **Lien "Créer un compte"** | **CLIQUER ICI** | Cliquez sur ce lien si vous ne possédez pas encore de compte pour ouvrir le formulaire d'inscription. |

---

## 3. Procédure Étape par Étape

1. **Saisir vos identifiants** :
   - Tapez votre e-mail dans le champ **Adresse e-mail** (**[1]**).
   - Tapez votre mot de passe dans le champ **Mot de passe** (**[2]**).
2. **Options de session** :
   - Cochez **Se souvenir de moi** (**[3]**) s'il s'agit de votre ordinateur personnel.
3. **Se connecter** :
   - Cliquez sur le bouton bleu **Se connecter** (**[4]**) ou appuyez sur la touche <kbd>Entrée</kbd> de votre clavier.
