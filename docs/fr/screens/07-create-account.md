# Guide Utilisateur : Créer un Compte Bancaire

[← Retour au Tableau de Bord](06-dashboard.md) | [Suivant : 08 - Modifier & Configurer un Compte →](08-edit-account.md)

---

L'écran **Créer un Compte** vous permet d'ajouter un nouveau compte bancaire à votre espace de gestion. Vous pouvez sélectionner un établissement existant ou en créer un nouveau, définir la typologie de compte et renseigner le solde d'ouverture.

---

## 2. Tableau de Référence des Actions

| Repère | Élément d'Interface | Type d'Action | Consigne |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Établissement Bancaire** | **SÉLECTIONNER** | Choisissez une banque parmi celles enregistrées (ex. BoursoBank, BNP Paribas) ou cliquez sur **"Créer une nouvelle banque..."** pour en ajouter une. |
| <kbd>2</kbd> | **Nom du Compte** | **RENSEIGNER** | Saisissez un libellé clair pour identifier le compte (ex. `Compte Courant Principal`, `Livret A`). |
| <kbd>3</kbd> | **Type de Compte** | **SÉLECTIONNER** | Choisissez la classification (Courant, Épargne, Investissement, Carte). Elle détermine la façon dont le solde est ventilé sur le tableau de bord. |
| <kbd>4</kbd> | **Solde Initial** | **RENSEIGNER** | Saisissez le solde de départ du compte avant le premier relevé bancaire importé (ex. `2845,50`). |
| <kbd>5</kbd> | **Bouton "Créer le compte"** | **CLIQUER ICI** | Cliquez pour valider la création du compte et être redirigé vers le tableau de bord. |

---

## 3. Procédure Étape par Étape

1. **Sélectionner ou créer l'établissement bancaire** :
   - Utilisez la liste déroulante (<kbd>1</kbd>) pour choisir votre banque.
   - Si votre banque ne figure pas encore dans la liste, choisissez l'option de création et renseignez son nom et son code couleur.
2. **Nommer votre compte** :
   - Dans le champ **Nom du compte** (<kbd>2</kbd>), entrez un intitulé explicite.
3. **Sélectionner le type de compte** :
   - Dans la liste déroulante **Type de compte** (<kbd>3</kbd>), sélectionnez la typologie appropriée.
4. **Définir le solde initial d'ouverture** :
   - Dans le champ **Solde initial** (<kbd>4</kbd>), indiquez votre solde bancaire de référence avant import des historiques.
5. **Enregistrer le compte** :
   - Cliquez sur le bouton vert **Créer le compte** (<kbd>5</kbd>) pour valider.
