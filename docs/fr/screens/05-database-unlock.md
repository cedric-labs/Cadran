# Guide Utilisateur : Déverrouillage de la Base de Données

[← Précédent : 04 - Chiffrement de la Base](04-database-encryption.md) | [Retour à l'Index Général](../README.md) | [Suivant : 06 - Tableau de Bord →](06-dashboard.md)

---

L'écran de **Déverrouillage de la Base de Données** s'affiche au lancement de Cadran dès lors que le chiffrement de la base est activé et que l'option de mémorisation sur l'appareil n'a pas été sélectionnée. Vous devez renseigner votre phrase secrète maîtresse pour ouvrir votre espace de travail.

## 2. Tableau de Référence des Actions

| Repère | Élément d'Interface | Type d'Action | Consigne |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Phrase Secrète Maîtresse** | **RENSEIGNER** | Saisissez votre phrase secrète de déchiffrement dans ce champ. |
| <kbd>2</kbd> | **Icône Afficher / Masquer** | **CLIQUER ICI** | Cliquez sur l'icône en forme d'œil pour afficher ou masquer les caractères saisis. |
| <kbd>3</kbd> | **Mémoriser sur cet appareil** | **OPTIONNEL** | Cochez cette case si vous souhaitez que cet appareil mémorise la clé et ignore cette demande lors des prochains lancements. |
| <kbd>4</kbd> | **Bouton "Déverrouiller"** | **CLIQUER ICI** | Cliquez sur ce bouton pour déverrouiller Cadran et accéder à vos comptes. |

---

## 3. Procédure Étape par Étape

1. **Saisir votre clé maîtresse** :
   - Cliquez dans le champ **Phrase secrète de déchiffrement** (**[1]**) et tapez votre clé.
2. **Vérifier votre saisie (Optionnel)** :
   - Cliquez sur l'icône œil (**[2]**) pour vérifier l'exactitude des caractères.
3. **Comportement futur au démarrage** :
   - Cochez **Mémoriser sur cet appareil** (**[3]**) pour vous affranchir d'un déverrouillage manuel la prochaine fois.
4. **Déverrouiller** :
   - Cliquez sur le bouton bleu **Déverrouiller la base** (**[4]**) ou appuyez sur <kbd>Entrée</kbd>.
   - Vous êtes immédiatement redirigé vers l'aperçu général de vos comptes.
