# Guide Utilisateur : Création de Compte

L'écran de **Création de Compte** configure votre profil utilisateur dans Cadran. Dès sa validation, Cadran initialise automatiquement un catalogue complet de catégories de revenus et de dépenses par défaut pour votre espace de travail.

## 2. Tableau de Référence des Actions

| Repère | Élément d'Interface | Type d'Action | Consigne |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Nom Complet** | **RENSEIGNER** | Saisissez votre nom d'affichage ou nom complet (ex. `Alice`). |
| <kbd>2</kbd> | **Adresse E-mail** | **RENSEIGNER** | Saisissez l'adresse électronique qui servira d'identifiant de connexion. |
| <kbd>3</kbd> | **Mot de Passe** | **RENSEIGNER** | Choisissez un mot de passe robuste (au moins 8 caractères). |
| <kbd>4</kbd> | **Confirmer le Mot de Passe** | **RENSEIGNER** | Ressaisissez à l'identique votre mot de passe pour confirmation. |
| <kbd>5</kbd> | **Bouton "S'inscrire"** | **CLIQUER ICI** | Cliquez sur ce bouton pour créer votre compte et accéder à votre espace de travail. |
| <kbd>6</kbd> | **Lien "Se connecter"** | **CLIQUER ICI** | Cliquez sur ce lien si vous possédez déjà un compte pour basculer vers le formulaire de connexion. |

---

## 3. Procédure Étape par Étape

1. **Renseigner votre profil** :
   - Cliquez dans le champ **Nom complet** (**[1]**) et tapez votre nom.
   - Cliquez dans le champ **Adresse e-mail** (**[2]**) et entrez votre adresse de courriel.
2. **Définir votre mot de passe** :
   - Tapez votre mot de passe secret dans **Mot de passe** (**[3]**).
   - Ressaisissez-le dans **Confirmer le mot de passe** (**[4]**).
3. **Valider** :
   - Cliquez sur le bouton bleu **S'inscrire** (**[5]**).
   - Vous êtes automatiquement authentifié et redirigé vers l'aperçu général de vos comptes.
