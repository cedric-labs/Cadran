# Guide Utilisateur : Modifier & Configurer un Compte

[← Retour à Créer un Compte](07-create-account.md) | [Suivant : 09 - Registre & Historique du Compte →](09-account-details.md)

---

L'écran **Modifier un Compte** permet d'actualiser les paramètres d'un compte bancaire existant, d'ajuster son solde initial d'ouverture ou de l'archiver lorsqu'il est clôturé.

---

## 2. Tableau de Référence des Actions

| Repère | Élément d'Interface | Type d'Action | Consigne |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Nom du Compte** | **RENSEIGNER** | Modifiez l'intitulé du compte si vous souhaitez le renommer. |
| <kbd>2</kbd> | **Type de Compte** | **SÉLECTIONNER** | Modifiez la typologie d'actif (Courant, Épargne, Investissement, Carte). |
| <kbd>3</kbd> | **Solde Initial** | **RENSEIGNER** | Ajustez le solde d'ouverture si vous devez corriger un décalage de pointage passé. |
| <kbd>4</kbd> | **Interrupteur d'Archivage** | **OPTIONNEL** | Activez cet interrupteur si le compte est clôturé. Le compte disparaîtra du tableau de bord tout en préservant son historique d'écritures. |
| <kbd>5</kbd> | **Bouton "Enregistrer les modifications"** | **CLIQUER ICI** | Cliquez pour appliquer et sauvegarder vos modifications. |

---

## 3. Procédure Étape par Étape

1. **Renommer le compte (optionnel)** :
   - Modifiez le texte du champ **Nom du compte** (<kbd>1</kbd>).
2. **Reclassifier le compte (optionnel)** :
   - Dans la liste déroulante **Type de compte** (<kbd>2</kbd>), basculez vers une autre catégorie si besoin.
3. **Corriger le solde d'ouverture (optionnel)** :
   - Dans le champ **Solde initial** (<kbd>3</kbd>), saisissez la valeur rectifiée.
4. **Archiver un compte clôturé** :
   - Activez l'interrupteur **Archiver ce compte** (<kbd>4</kbd>) pour le masquer des vues actives sans supprimer ses opérations.
5. **Enregistrer** :
   - Cliquez sur le bouton vert **Enregistrer les modifications** (<kbd>5</kbd>).
