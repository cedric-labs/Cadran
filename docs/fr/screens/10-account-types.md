# Guide Utilisateur : Types de Comptes Personnalisés & Groupes d'Actifs

[← Retour au Registre du Compte](09-account-details.md) | [Suivant : 11 - Statuts d'Écritures Personnalisés →](11-account-statuses.md)

---

L'écran **Types de Comptes** vous permet de définir et personnaliser le mode de classification de vos comptes bancaires. Chaque typologie est rattachée à un groupe d'actifs (Liquidités, Épargne & Placements, ou Dettes / Découverts), garantissant un calcul fidèle de votre patrimoine net.

## 3. Comprendre les Groupes d'Actifs Financiers

Cadran ventile chaque compte au sein de l'un des trois groupes d'actifs suivants :

1. **Liquidités** : Comptes à forte disponibilité (Compte courant, Espèces, Portefeuilles numériques).
2. **Épargne & Placements** : Actifs productifs d'intérêts et d'investissements (Livrets d'épargne, Actions, Obligations, Crypto-actifs).
3. **Dettes / Découverts** : Engagements à solde négatif (Cartes à débit différé, Prêts personnels, Emprunts immobiliers).

---

## 4. Procédure Étape par Étape

1. **Créer un type de compte personnalisé** :
   - Cliquez sur le bouton bleu **Nouveau type de compte** (<kbd>1</kbd>).
   - Dans la fenêtre modale, donnez un nom distinct (ex. `Compte Jeune`, `Dépôt à terme`), choisissez une couleur, une icône et le groupe d'actifs parent.
2. **Modifier un type existant** :
   - Cliquez sur le bouton crayon **Modifier** (<kbd>4</kbd>) sur la ligne souhaitée.
   - Ajustez le style visuel ou le groupe d'appartenance et validez l'enregistrement.
