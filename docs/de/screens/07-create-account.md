# Benutzerhandbuch: Bankkonto anlegen

[← Zurück zum Dashboard](06-dashboard.md) | [Weiter: 08 - Konto bearbeiten & konfigurieren →](08-edit-account.md)

---

Der Bildschirm **Konto erstellen** ermöglicht das Hinzufügen eines neuen Kontos zu Ihrem Arbeitsbereich. Sie können ein bestehendes Bankinstitut auswählen oder ein neues registrieren, den Kontotyp festlegen und den Eröffnungssaldo definieren.

---

## 2. Referenztabelle der Aktionen

| Markierung | Bedienelement | Aktionstyp | Handlungsanweisung |
| :---: | :--- | :---: | :--- |
| <kbd>1</kbd> | **Bankinstitut** | **AUSWÄHLEN** | Wählen Sie eine Bank aus der Liste (z. B. Deutsche Bank, ING, Sparkasse) oder wählen Sie **"Neue Bank anlegen..."**. |
| <kbd>2</kbd> | **Kontoname** | **AUSFÜLLEN** | Vergeben Sie einen eindeutigen Namen (z. B. `Hauptgirokonto`, `Notgroschen`). |
| <kbd>3</kbd> | **Kontotyp** | **AUSWÄHLEN** | Wählen Sie die Klassifizierung (Giro, Sparen, Anlage oder Kreditkarte). Dies steuert die Einordnung im Dashboard. |
| <kbd>4</kbd> | **Eröffnungssaldo** | **AUSFÜLLEN** | Tragen Sie den Kontostand vor dem ersten importierten Auszug ein (z. B. `2845,50`). |
| <kbd>5</kbd> | **Schaltfläche "Konto erstellen"** | **HIER KLICKEN** | Klicken Sie hier, um das Konto anzulegen und zum Dashboard zurückzukehren. |

---

## 3. Schritt-für-Schritt-Anleitung

1. **Bankinstitut auswählen oder anlegen**:
   - Wählen Sie Ihre Bank im Dropdown-Menü (<kbd>1</kbd>).
   - Falls die Bank fehlt, wählen Sie die Erstellungsoption und vergeben Sie Namen und Farbcode.
2. **Konto benennen**:
   - Tragen Sie im Feld **Kontoname** (<kbd>2</kbd>) eine aussagekräftige Bezeichnung ein.
3. **Kontotyp bestimmen**:
   - Wählen Sie im Menü **Kontotyp** (<kbd>3</kbd>) den passenden Kontotyp aus.
4. **Eröffnungssaldo erfassen**:
   - Geben Sie im Feld **Eröffnungssaldo** (<kbd>4</kbd>) Ihren Startkontostand ein.
5. **Konto speichern**:
   - Klicken Sie auf die grüne Schaltfläche **Konto erstellen** (<kbd>5</kbd>).
